# custom-neovide 0.16.2-custom.4

基于 neovide 0.16.2 的自定义版本。

## 本版新增

### Windows 文件右键菜单

- 原生菜单栏「常用」新增「注册系统菜单 / 注销系统菜单」。
- 注册后，文件资源管理器的文件右键菜单显示「使用 neovim 打开」，图标使用当前运行的 Neovide 图标。
- 打开命令带 `--reuse-instance`，优先复用正在运行的实例。
- 仅写当前用户注册表 `HKCU\Software\Classes\*\shell\Neovide`，无需管理员权限；注销只删除该项，不影响文件关联和「打开方式」列表。

### 多行文件 Tab

- 新增 Neovide 顶部多行文件栏，文件过多时按窗口宽度自动换行和增高，不再局限于 bufferline.nvim 的单行 tabline。
- 支持文件图标、当前缓冲区高亮、未保存修改标记、点击切换、点击 `×` 关闭，以及窗口缩放后的自动重排。
- 保留原有 `BufferLine*` 命令与缓冲区快捷键，仅替换单行外观；普通终端 Neovim 仍使用原 bufferline。
- 原 bufferline 最右侧的 `1、2、3` 是 Neovim 原生 tabpage（工作区）编号，不是文件缓冲区序号；新文件栏不再显示这些编号。

### 选区删除行为优化

- 修复插入模式下 `End → Shift+Home → Backspace/Delete` 将换行符一并删除、导致后一行并上来的问题。
- 现在只删除当前行文本，保留空行并留在插入模式；空行执行相同操作也不会合并相邻行。
- 普通模式的选区删除行为保持不变。

## nvim 配置同步

本版功能位于 nvim 侧配置，仓库同步副本在 `CUSTOMIZATIONS/nvim/`。已有本机配置的用户请按自身配置合并，不要直接覆盖其他个性化设置：

- `neovide_menu.lua`、`neovide_shell_menu.lua`、`neovide_buffer_tabs.lua`、`keymaps.lua` → `lua/config/`
- `bufferline.lua` → `lua/plugins/`

原生菜单栏仍需启用：

```lua
if vim.g.neovide then
  vim.g.neovide_menubar = true
end
```

重启 Neovide 后生效。多行文件栏可执行 `:NeovideRefreshBufferTabs` 手动刷新。
