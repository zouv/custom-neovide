# custom-neovide 0.16.2-custom.3

基于 neovide 0.16.2 的自定义版本。

## 本版新增

### 关闭窗口到系统托盘（Windows）

- 点窗口 X / Alt+F4 不再退出，而是隐藏窗口并驻留系统托盘；nvim 进程、缓冲区与撤销历史全部保留。
- 托盘左键恢复窗口；右键菜单提供「显示窗口 / 退出 Neovide」。
- 托盘「退出」会先恢复窗口，再走 nvim 的确认退出流程（未保存修改仍会提示）。
- 托盘图标只在窗口隐藏期间存在；窗口恢复后自动移除。
- 隐藏期间暂停渲染调度，CPU 占用接近 0（实测隐藏 4 秒 CPU 增量 0.000s）。
- 新增设置 `g:neovide_tray`（Windows，默认 `false`）；托盘创建失败会自动回退为正常关闭退出。
- 只影响窗口关闭按钮；nvim 内 `:qa` / `:qa!` 仍正常退出。

### 帮助 → 关于

- 原生菜单栏「帮助」新增「关于」，弹出原生对话框显示 Neovide 版本、Neovim 版本、系统与配置目录。
- 菜单与文本由 nvim 侧 `neovide_menu.lua` 定义，调整内容不需要重新编译 Neovide。

### 默认单例运行（Windows/macOS）

- 再次启动 Neovide 时默认复用已有进程：窗口隐藏到托盘时自动恢复并聚焦，窗口可见时直接切到前台。
- 带文件启动时在已有实例中打开文件；`--new-window` 可在已有进程内新开窗口。
- 新增 `--new-instance`（别名 `--no-single-instance`），需要独立进程时显式指定。
- 与旧版本实例共存时，纯激活请求会检测版本不一致并正常启动新实例，不会静默退出；带文件/`--new-window` 的请求仍交给已有实例。
- `--server` / `--wsl` 不参与单例复用。

## 配置示例

```lua
if vim.g.neovide then
  vim.g.neovide_menubar = true
  vim.g.neovide_tray = true
end
```

菜单内容参考 `CUSTOMIZATIONS/nvim/neovide_menu.lua`（含「帮助.关于」）。

## 便携包用法

`neovide-0.16.2-custom.3-win-x64-portable.zip` 解压后：

1. 双击 `register-file-assoc.bat` 注册文件关联（打开命令会带 `--reuse-instance`）
2. 或直接运行 `neovide.exe`

nvim 侧还需要：

1. 设置 `vim.g.neovide_menubar = true` 启用原生菜单栏（可选）
2. 设置 `vim.g.neovide_tray = true` 启用关闭到托盘（可选，默认关闭）

## 注意

- 本便携包使用 skia 预编译二进制（动态 CRT），需要已安装 VC++ 运行库（Windows 10/11 通常自带）。
- 若 `nvim` 不在系统 PATH，请在 neovide 的 `config.toml` 里配置 `neovim-bin`。
- `g:neovide_tray` 默认关闭；升级后行为不变，需要显式开启。
- 菜单栏启用时渲染器使用 OpenGL；如需 D3D，请关闭 `neovide_menubar`。
