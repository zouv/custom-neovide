# custom-neovide 0.16.2-custom.2

基于 neovide 0.16.2 的自定义版本。

## 本版新增

### Windows 原生菜单栏

- 菜单内容由 nvim 的 `:amenu` 定义；Neovide 启动后读取 `menu_get()` 渲染成系统原生菜单栏，点击后通过 `:emenu` 在当前模式下执行。
- 修改菜单不需要重新编译 Neovide，执行 `:NeovideRefreshMenu` 即可刷新。
- 不再需要按 Alt 打开菜单：单按 Alt、Alt+字母、F10 全部交给 nvim（AltGr 除外）。
- 新增设置 `g:neovide_menubar`（默认 `false`）；全屏和 `--frame none` 下自动隐藏。
- 开启菜单栏时渲染器自动使用 OpenGL（D3D 的合成交换链没有 GDI 重定向表面，无法显示系统菜单栏）。

示例菜单定义见 `CUSTOMIZATIONS/nvim/neovide_menu.lua`，包含文件 / 编辑 / 视图 / 常用 / 帮助五组。

### 关闭最后一个文件保留窗口

- 删除最后一个文件缓冲区（bufferline 的 ×、`:bd`、`<leader>bd`）后，窗口保留并显示 snacks dashboard。
- 在最后一个窗口上 `:q` / `:wq` / `:x` 时不再退出，同样回到欢迎界面。
- `:qa` / `:qa!` 和窗口关闭按钮仍然正常退出。
- 判断“最后一个窗口”时排除 noice / which-key / notify 等浮动窗口。

示例配置见 `CUSTOMIZATIONS/nvim/neovide_welcome.lua`。

## 本版修复

- **窗口全透明**：菜单栏触发 OpenGL 时窗口仍带有 `WS_EX_NOREDIRECTIONBITMAP`，导致画面无处落地、整个窗口透明；现已同步跳过该窗口属性。
- **`:q` 仍直接退出**：noice 的浮动窗口让 `nvim_list_wins()` 计数失真，改为只统计非浮动窗口。

## 便携包用法

`neovide-0.16.2-custom.2-win-x64-portable.zip` 解压后：

1. 双击 `register-file-assoc.bat` 注册文件关联（打开命令会带 `--reuse-instance`）
2. 或直接运行 `neovide.exe`

nvim 侧还需要：

1. 设置 `vim.g.neovide_menubar = true`（可选，不设置则没有菜单栏）
2. 用 `:amenu` 定义菜单内容
3. 如需“关闭最后文件保留窗口”，参考 `neovide_welcome.lua` 注册响应式 autocmd

## 注意

- 本便携包使用 skia 预编译二进制（动态 CRT），需要已安装 VC++ 运行库（Windows 10/11 通常自带）。
- 若 `nvim` 不在系统 PATH，请在 neovide 的 `config.toml` 里配置 `neovim-bin`。
- 菜单栏启用时使用 OpenGL 渲染；如需 D3D，请关闭 `neovide_menubar`。
